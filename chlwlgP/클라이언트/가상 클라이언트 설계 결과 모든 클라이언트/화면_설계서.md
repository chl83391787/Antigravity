# 📱 플로뜰리에(Flottelier) - 김스테이 B2B 화면 설계서 (UI/UX Specification)

> **프로젝트**: 프리미엄 독채 스테이 & 한옥 감성 숙소 맞춤 B2B 어메니티 & 실시간 견적 플랫폼  
> **기반 페르소나**: 김스테이 / 정우진 (38세, 프리미엄 감성 독채 스테이 & 웰니스 숙소 호스트)  
> **입력 파일**: `가상 클라이언트 설계 결과/사이트맵.md`, `가상 클라이언트 설계 결과/서비스_흐름도.md`, `김스테이_가상클라이언트_분석결과.md`  
> **저장 폴더**: `클라이언트/가상 클라이언트 설계 결과/` 및 `가상 클라이언트 설계 결과/`  
> **인코딩**: UTF-8

## 1. 프로젝트 및 설계 범위

본 화면 설계서는 프리미엄 감성 스테이 호스트 '김스테이(정우진)'의 핵심 요구사항을 구현하기 위해 정의된 **11개 핵심 화면(P-01 ~ P-11)**, **3개 레이어드 모달(M-02 ~ M-04)**, **3개 예외 화면(EX-01 ~ EX-03)**의 영역 구성, UI 컴포넌트, 인터랙션, 표시 데이터, 유효성 검사 규칙 및 반응형 가이드를 기술한 상세 명세서입니다.

## 2. 화면 ID 규칙 및 전체 화면 목록

### 2.1 화면 ID 명명 규칙
- `P-xx`: 1차, 2차, 3차 일반 웹 페이지 (Page)
- `M-xx`: 팝업 오버레이 및 인터랙티브 레이어드 모달 (Modal)
- `EX-xx`: 유효성 실패, 재고 부족, 404 등 예외 처리 화면 (Exception)

## 3. 화면별 상세 UI 및 인터랙션 설계

### 3.1 P-01: B2B 메인페이지 (Stay B2B Main)
* **목적**: 스테이 호스트에게 락스 냄새 없는 4차 정련 소창 어메니티의 가치를 전달하고 20/50/100장 번들 발주 유도.
* **구성 영역**:
  - **헤더**: 플로뜰리에 B2B 로고, GNB, `[세금계산서 즉시 발행 띠배너]`, `[실시간 견적서 PDF 버튼]`
  - **히어로**: "스테이의 품격을 높이는 4차 정련 소창 어메니티 - 20장/50장/100장 B2B 대량 특별할인"
  - **번들 그리드**: 독채 20장 팩(25%↓), 부티크 50장 팩(35%↓, 베스트), 호텔 100장 팩(40%↓) 카드
  - **실시간 계산기**: 슬라이더 조작 시 실시간 장당 단가(9,900원) 및 절감액 자동 갱신
  - **핵심 프리뷰**: Canvas 로고 자수 시뮬레이터 배너 + 국/영문 리추얼 카드 실물 컷
  - **푸터**: B2B 사업자 상담 핫라인, KC 4無 안전 인증서, 무비닐 패키징 보증

### 3.2 P-03: 번들 상품 상세 페이지 (Bundle Detail)
* **목적**: 50장 스탠다드 번들의 상세 스펙 확인, 3배 빠른 건조 데이터 검증, 고리형 루프 옵션 선택.
* **UI 요소**:
  - 50장 번들 실물 사진 갤러리 (상부장 1/3 슬림 적재 컷)
  - 3배 빠른 초고속 건조 인터랙티브 Slider (테리 타월 4시간 vs 소창 타월 1시간)
  - 순면 루프(고리) 마감 유무 라디오 버튼 (+장당 0원 무료 프로모션)
  - `[숙소 로고 자수 커스텀 (P-05)]` 및 `[실시간 견적서 PDF (M-04)]` 플로팅 CTA

### 3.3 P-05 & M-03: 숙소 로고 자수 센터 & Canvas 시뮬레이터
* **목적**: 숙소 로고(AI, PNG)를 업로드하여 0.05초 만에 소창 패브릭 위에 실사 자수 합성 시안 확인.
* **UI 요소**:
  - 드래그 앤 드롭 파일 업로더 (AI, SVG, 고해상도 PNG 지원, 최대 20MB)
  - 자수 실 색상 스와치 7종 (샴페인 골드, 포레스트 그린, 플래티넘 실버, 앤티크 차콜 등)
  - 자수 위치 선택 (우측 하단 기본, 중앙 상단)
  - HTML5 Canvas 실시간 렌더링 뷰어 (줌 인/아웃 지원)
  - `[1:1 디자이너 검수 신청]` 및 `[시안 이미지 다운로드]` 버튼

### 3.4 P-07 & M-04: 실시간 자동 견적 & 세금계산서 센터
* **목적**: 전화 상담 없이 1초 만에 법인 직인이 날인된 공식 견적서 PDF를 다운로드하고 세금계산서 신청.
* **UI 요소**:
  - 공급가액, 부가세(10%), 수량별 할인액, 배송비(0원) 자동 계산 테이블
  - `[직인 날인 견적서 PDF 다운로드]` 원클릭 버튼 (클릭 시 브라우저 PDF 즉시 저장)
  - 사업자등록번호 10자리 입력 필드 및 국세청 실시간 유효성 검증 API 연동
  - 전자세금계산서 수신용 담당자 이메일 입력창

### 3.5 P-10: B2B 장바구니 & 법인 결제 (Checkout)
* **목적**: 법인카드 또는 가상계좌로 안전하게 발주하고 100% 무비닐 벌크 포장으로 출고 확정.
* **UI 요소**:
  - 발주 번들 품목 및 로고 자수 시안 요약 썸네일
  - 국/영문 리추얼 카드 무료 동봉 수량 자동 표시 (50장 주문 시 카드 50매 0원)
  - 배송지 입력 폼 (스테이 현장 직배송 및 수령 희망일 지정)
  - 결제 수단: 법인카드 1초 결제 / 가상계좌(전자세금계산서 익일 자동 발행)

## 4. 유효성 검사 규칙 및 오류 피드백

| 입력 항목 | 유효성 검사 규칙 (Validation Rule) | 오류 시 시스템 피드백 (Error Feedback) |
| :--- | :--- | :--- |
| **숙소 로고 파일** | 확장자: `.ai`, `.svg`, `.png` / 해상도 1000px 이상 / 용량 20MB 이하 | `[EX-01]` "지원하지 않는 파일 형식이거나 저화질입니다. AI/PNG 파일을 업로드해 주세요." |
| **사업자등록번호** | 숫자 10자리 형식 (3-2-5 자리) 및 국세청 체크섬 알고리즘 검증 | "올바른 사업자등록번호 10자리를 입력해 주세요. (휴폐업 여부 확인)" |
| **세금계산서 이메일** | RFC 5322 표준 이메일 정규식 (`@` 및 도메인 포함) | "정확한 세금계산서 수신용 이메일 주소를 입력해 주세요." |
| **발주 수량** | 최소 20장 이상 (20장 미만 입력 불가) | "스테이 B2B 번들은 최소 20장부터 대량 발주가 가능합니다." |
| **초대형 발주 수량** | 300장 초과 시 | `[EX-02]` "300장 이상 대량 발주는 전담 매니저를 통해 납기 일정을 조율해 드립니다." |

## 5. 반응형 뷰포트 기준 (Responsive Breakpoints)

* **데스크톱 (Desktop - 1440px 이상)**:
  - 4열 그리드 레이아웃, Canvas 자수 시뮬레이터 좌우 2단 분할 뷰, 실시간 견적서 PDF 우측 스티키 바 고정.
* **태블릿 (Tablet - 768px ~ 1024px)**:
  - 2열 그리드 레이아웃, 상단 탭 스크롤 지원, 자수 시뮬레이터 상하 2단 배치.
* **모바일 (Mobile - 375px ~ 767px)**:
  - 1열 풀 너비 카드, 하단 스티키 CTA 바 (`[견적서 PDF 출력]` / `[50장 번들 발주]`), 원클릭 터치 최적화.

## 6. 웹 접근성 요구사항 (WCAG 2.1 AA)

1. **텍스트 명도 대비**: 모든 본문 텍스트와 배경 간 명도 대비 4.5:1 이상 유지 (`#232527` on `#FAFDFD`).
2. **키보드 접근성**: 모든 폼 입력 필드, 자수 실 스와치, PDF 다운로드 버튼에 `Tab` 및 `Enter/Space` 키보드 포커스 링 제공.
3. **대체 텍스트 (Alt Text)**: Canvas 자수 프리뷰 및 성적서 이미지에 정밀한 스크린 리더용 `aria-label` 제공.

## 7. 가정 사항 모음 (Assumptions)

- `[가정 1]`: 로고 파일 업로드 시 벡터 변환이 불가능한 저화질 비트맵 이미지는 디자이너 무료 보정 카카오톡 채널로 자동 연결됨.
- `[가정 2]`: 300장 이상 대량 주문 시 기본 제작 기간(D+2) 외에 분할 순차 출고가 가능하도록 시스템에 사전 확약 안내를 둠.
- `[가정 3]`: 세금계산서는 결제 완료 즉시 국세청 홈택스 시스템으로 전자 발급 예약 데이터가 자동 전송됨.
