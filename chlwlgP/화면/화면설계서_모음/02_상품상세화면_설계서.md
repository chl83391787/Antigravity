# [화면 설계서] 02. 상품 상세 화면 (SHOP / Product Detail Screen)

---

## 1. 기본 정보
- **화면명**: 상품 상세 페이지 (Product Detail & Custom Preview)
- **화면 목적**: 
  - 김다꾸(실시간 자수 프리뷰), 김마미(KC 인증 원본/맘리뷰), 김예민(500% HD 줌/체험팩), 김환경(친환경 정보표/무비닐 포장) 4대 요구사항을 단 하나의 화면에서 완벽하게 제공.
  - 4차 정련 완료 뱃지와 4無 저자극 인증, 투명한 제조 공정 데이터를 통해 높은 가격의 이유를 명확히 제시하고 즉시 결제로 전환 유도.

---

## 2. 주요 콘텐츠
- **4차 정련 고정 뱃지**: `[받아서 바로 사용하세요! 4차 정련 완료]`
- **공인 인증 모달**: 더마테스트 엑설런트 & KC 무형광·무표백 성적서 1초 공식 조회
- **실시간 자수 Live Preview**: 사용자 문구 입력 시 글씨체, 색상, 위치가 3D/2D 상품 이미지에 즉시 합성
- **봉제선 500% HD 마그니파이어 줌**: 가장자리 마감, 부드러운 라벨, 실밥 상태를 초밀착 확대 확인
- **세탁 전/후 1:1 비교**: 세탁 50회 후 수축 크기(cm), 두께, 보풀 변화 비교 슬라이더
- **친환경 정보표 (Eco Specs Sheet)**: 탄소/물 절감률, 3년 수명 연수, 국산 100%
- **장당 단가 자동 계산기**: 낱장, 3장, 5장, 10장 세트 선택 시 장당 단가(원) 표시

---

## 3. 인터페이스 요소
- **컬러 스와치**: 크림, 베이지, 연두, 브라운 스와치 버튼
- **마감 선택 스위치**: 고리 있음 / 푸프 타입 / 무라벨 (Label-free)
- **자수 입력 폼**: 텍스트 입력창, 폰트 3종 선택, 자수 실 컬러 4종 선택
- **맘리뷰 전용 3중 필터**: 피부타입(건성/민감성/알레르기) x 아기연령 x 세탁 횟수
- **포장 선택 옵션**: 무비닐 0% 최소 포장 체크박스 & 선물 포장 보기
- **스티키 결제 바**: `[네이버페이 1초 결제]` & `[1장 체험팩 신청 (체험비 100% 페이백)]`

## 5. 작동 방식
1. **자수 프리뷰 연동**: 텍스트 입력창에 이름/문구를 타이핑하면 Canvas 기술로 수건 고화질 이미지 위에 자수 폰트와 실 색상이 실시간으로 합성되어 표시됨.
2. **500% HD 마그니파이어**: 이미지 위 돋보기 아이콘을 마우스 오버하거나 터치하면 500% 고화질 크롭 렌즈가 동작하여 봉제 마감을 확인 가능.
3. **장당 단가 갱신**: 세트 수량을 1장 ➔ 5장으로 변경 시 `[총 22,500원 (장당 4,500원)]` 메시지가 실시간 계산되어 출력됨.

---

## 6. 연결 화면 및 이동 구조
- **`[인증서 원본 보기]` 클릭 시**: 공인 인증기관 조회 팝업창 모달 연결
- **`[1장 체험팩 신청]` 클릭 시**: 체험팩 구매 & 100% 본품 페이백 쿠폰 발급 페이지 연결
- **`[네이버페이 결제]` 클릭 시**: 네이버페이 모바일 결제 팝업 진입

---

## 7. 사용자 경로 (User Journey)
1. 메인 또는 검색을 통해 상품 상세 진입
2. 상단 4차 정련 뱃지 및 KC 인증서 확인으로 신뢰 확보
3. 자수 프리뷰를 통해 커스텀 결과물 미리보기
4. 봉제선 500% HD 줌으로 마감 퀄리티 검증 후 `네이버페이 1초 결제`

---

## 8. 비고 · 주석
- **모바일 최적화**: 모바일 기기 접속 시 자수 프리뷰 모듈과 결제 버튼이 한 손 엄지손가락으로 쉽게 조작되도록 대형 터치 타겟(최소 48px 이상) 적용.
