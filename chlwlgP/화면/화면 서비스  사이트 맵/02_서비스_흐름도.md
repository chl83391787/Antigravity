# [2. 서비스 흐름도 제작] 플로뜰리에 (Flottelier) 서비스 흐름도 (Service Flowchart)

> **프로젝트명**: 플로뜰리에 (Flottelier) - 4차 정련 완료 소창 라이프스타일 커머스 & 에코 리추얼 플랫폼  
> **기반 문서**: `[1. 사이트맵 제작]` 문서 (`01_사이트맵_제작.md`) 및 5인 가상 클라이언트 분석 결과  
> **목적**: 사용자 진입부터 상품 탐색, 맞춤 옵션 선택, 결제, 배송, 사후 케어까지의 종합 서비스 흐름도(Service Flowchart) 및 페르소나별 시나리오 정의

## 1. 전체 사용자 통합 서비스 흐름도 (Overall Service Flow)

Below is the complete user flow from initial acquisition to after-sales care:

```mermaid
flowchart TD
    Start([사용자 웹사이트 진입]) --> Acquisition{진입 경로}
    
    Acquisition -- "SNS / 인스타그램 광고" --> MainHero[메인 비주얼 & 브랜드 선언문]
    Acquisition -- "네이버/구글 키워드 검색" --> ShopDirect[SHOP / 라인업 전체보기]
    Acquisition -- "오프라인 팝업스토어 QR" --> PopUpModal[팝업스토어 사전예약 모달]

    MainHero --> CoreTrust[4차 정련 완료 뱃지 & KC 인증 확인]
    CoreTrust --> NavChoice{원하는 정보 탐색}

    NavChoice -- "소창 길들이기가 불안함" --> CareGuide[RITUAL & CARE: 4단계 타임라인]
    NavChoice -- "안전성/인증 확인 원함" --> CertModal[ABOUT: KC 인증서 & 4無 원본]
    NavChoice -- "바로 구매/제품 탐색" --> ShopDirect
    NavChoice -- "부담 없이 체험 희망" --> TrialPack[1장 체험팩 신청]

    ShopDirect --> ProductDetail[상품 상세 페이지 진입]
    TrialPack --> TrialCheckout[체험팩 결제 ➔ 본품 100% 환급 쿠폰 발급]

    ProductDetail --> InteractiveUX{핵심 인터랙션 체험}
    
    InteractiveUX -- "김예민: 마감 퀄리티 확인" --> HDZoom[500% HD 확대보기 마그니파이어]
    InteractiveUX -- "김다꾸: 나만의 타월 제작" --> CustomEmb[실시간 Canvas 자수 프리뷰]
    InteractiveUX -- "김마미: 실속 단가 계산" --> PriceCalc[낱장/세트 장당 단가 계산기]
    InteractiveUX -- "김환경: 친환경 포장 선택" --> ZeroPlastic[무비닐 0% 포장 옵션 선택]

    HDZoom --> Decision{구매 결정}
    CustomEmb --> Decision
    PriceCalc --> Decision
    ZeroPlastic --> Decision

    Decision -- "1초 간편 결제" --> PayNaver[네이버페이 / 카카오페이 1초 결제]
    Decision -- "선물하기 선택" --> GiftOption[감성 선물 패키징 & 메시지 카드 작성] --> PayNaver

    PayNaver --> OrderComplete[주문 완료 & 카카오 알림톡 발송]
    OrderComplete --> PostPurchase{사후 서비스 여정}

    PostPurchase -- "피부 미맞춤 발생 시" --> RefundReq[피부 미맞춤 100% 안심 환불 접수]
    PostPurchase -- "3년 사용 후 낡은 소창" --> Upcycling[3년 수명 업사이클 가이드 확인]
    PostPurchase -- "동일 옵션 추가 구매" --> QuickReorder[1-Click 재구매 센터에서 1초 주문]
```

## 2. 페르소나 5인별 맞춤 서비스 흐름도

### 2.1 Flow A: 김예민 (초민감 피부 & 안전 검증 유저)
```mermaid
sequenceDiagram
    autonumber
    actor Customer as 김예민 고객
    participant Main as 메인/상세 화면
    participant Cert as KC/4無 인증 모달
    participant Trial as 1장 체험팩 시스템
    participant Refund as 안심 환불 센터

    Customer->>Main: 4차 정련 완료 뱃지 클릭 진입
    Main->>Cert: KC 인증 및 4無(무형광/무표백) 성적서 원본 요청
    Cert-->>Customer: 국가 공인 시험기관 PDF/고화질 모달 표시
    Customer->>Main: 500% HD 줌 기능으로 봉제선 및 무라벨 마감 확인
    Customer->>Trial: 1장 체험팩 신청 (피부 적응 테스트용)
    Trial-->>Customer: 체험팩 배송 + 본품 구매 시 100% 환급 쿠폰 즉시 발급
    alt 피부 트러블 미발생
        Customer->>Main: 100% 환급 쿠폰 적용 후 본품 세트 구매
    else 피부 미맞춤 발생
        Customer->>Refund: 피부 미맞춤 안심 환불 접수 (100% 무료 교환/환불)
    end
```

---

### 2.2 Flow B: 김다꾸 (감성 커스텀 & 선물 구매 유저)
```mermaid
sequenceDiagram
    autonumber
    actor Customer as 김다꾸 고객
    participant Lookbook as 에디토리얼 룩북
    participant Custom as 커스텀 자수 스튜디오
    participant Packaging as 감성 패키징 시스템
    participant Order as 주문 결제

    Customer->>Lookbook: 감성 욕실 연출 룩북 탐색
    Lookbook->>Custom: 룩북 속 제품 1-Click 자수 시뮬레이터 진입
    Customer->>Custom: 자수 문구 입력, 폰트/실 색상/위치 선택
    Custom-->>Customer: Canvas 렌더링 기반 실시간 3D/2D 자수 실물 합성 이미지 제공
    Customer->>Packaging: 고급 소창 끈 선물 포장 및 메시지 카드 템플릿 선택
    Customer->>Order: 자수+포장 옵션 최종 확인 후 결제 완료
```

### 2.3 Flow C: 김마미 (가성비 & 아기 위생 유저)
```mermaid
sequenceDiagram
    autonumber
    actor Customer as 김마미 고객
    participant Main as 메인 / SHOP
    participant Review as 맘리뷰 필터

    participant Pay as 1초 결제

    Customer->>Main: '아기용 가제/데일리 소창' 카테고리 진입
    Main->>Review: '아기 연령별 / 실사용 맘리뷰' 필터 선택
    Review-->>Customer: 세탁 50회 이상 한 실제 엄마들의 부드러움 증대 후기 출력
    Customer->>Calc: 4장 세트 선택 시 장당 단가 자동 계산 확인 (낱장 대비 15% 절감)
    Customer->>Pay: 네이버페이 1초 간편결제 완료
```


## 3. 핵심 기능별 비즈니스 로직 & 예외 처리

### 3.1 1장 체험팩 100% 환급 쿠폰 발급 로직
1. **조건**: 동일 회원 계정당 최초 1회에 한함.
2. **프로세스**:
   - 체험팩 결제 완료 즉시 마이페이지 및 알림톡으로 `[본품 100% 환급 쿠폰]` 자동 발급.
   - 본품 구매 시 쿠폰 적용 ➔ 체험팩 결제 금액 전액 할인 차감.
3. **예외 처리**:
   - 비회원 구매 시 회원가입 전환 안내 팝업 표시.

### 3.2 피부 미맞춤 안심 환불 접수 로직
1. **조건**: 제품 수령 후 14일 이내, 1장 체험 후 피부 미맞춤 발생 시.
2. **프로세스**:
   - `COMMUNITY > 안심 환불 센터`에서 간편 사유 입력 접수.
   - 택배사 자동 수거 지시 및 제품 수거 후 100% 전액 환불.

### 3.3 오프라인 팝업스토어 사전 예약 로직
1. **조건**: 타임슬롯당 최대 15명 정원 제한.
2. **프로세스**:
   - 실시간 잔여 인원 확인 ➔ 예약 완료 시 예약 바코드 생성 ➔ 카카오 알림톡 발송.
   - 취소 발생 시 대기 고객에게 수동/자동 알림톡 전송.
