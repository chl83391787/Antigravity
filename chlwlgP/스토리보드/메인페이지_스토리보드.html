8. 접근성 요구사항 (Web Accessibility Specifications)

♿ 8. 웹 접근성 요구사항 (WCAG 2.1 AA & KWCAG 2.2 준수 명세)

모든 사용자가 장애 유무와 관계없이 메인페이지의 모든 정보와 기능에 평등하게 접근하도록 보장하는 표준 준수 지침입니다.

🏷️ 8.1 WAI-ARIA & 시맨틱 구조화
  • 시맨틱 태그: <header>, <nav>, <main>, <section>, <footer>
  • 주 내비게이션 랜드마크: role="navigation", aria-label="주 메뉴"
  • 모달 대화상자: role="dialog", aria-modal="true"
  • 동적 갱신 영역: aria-live="polite" 적용
⌨️ 8.2 키보드 탐색 & 포커스 제어
  • 스킵 네비게이션: .skip-nav:focus 최상단 본문 스킵 제공
  • 논리적 Focus 순서: GNB ➔ 히어로 ➔ 뱃지 ➔ 상품 ➔ 푸터 1:1 보장
  • 명확한 Focus Ring: :focus-visible 최소 3px 테두리 하이라이트
  • Focus Trap: 모달 열림 시 키보드 포커스 모달 내부 갇힘 제어
🖼️ 8.3 대체 텍스트 & 미디어 접근성
  • 의미 있는 alt 속성: 제품, 인증서, 지도 이미지 상세 alt 수록
  • 장식용 그래픽: aria-hidden="true" 스크린리더 무시 처리
  • 스크린리더 전용 텍스트: .sr-only 클래스로 텍스트 동시 전달
🎨 8.4 명도 대비 & 폼 오류 피드백
  • 명도 대비: 본문 텍스트 4.5:1 이상, 대형 UI 3.0:1 이상 준수
  • 폼 라벨링: <label for="..."> 명시적 연결
  • 오류 안내: aria-invalid="true" 및 오류 메시지 음성 출력
  • 줌 200%: 글자 확대 및 화면 리플로우 수직 배치 반응형 적용
