## 2. 사용자 여정 플로우 (User Journey Flows)

1. **신규 방문자 전환 플로우 (First-time Trial)**:
   - 메인 히어로 (P-01) ➔ 4차 정련 보증 확인 (P-02/P-03) ➔ 1장 체험팩 신청 (P-06) ➔ 본품 100% 환급 쿠폰 발급
2. **선물 구매자 개인화 플로우 (Custom Gifting)**:
   - GIFT 메뉴 (P-09) ➔ 실시간 Canvas 자수 문구/실 색상 입력 ➔ 패키징 선택 ➔ N Pay 1초 간편 결제
3. **오프라인 팝업 예약 플로우 (O2O Booking)**:
   - 메인 팝업 배너 (P-01) ➔ 성수 쇼룸 위치 확인 (P-08) ➔ 타임슬롯 선택 모달 ➔ 3초 예약 완료 및 알림톡 수신
4. **빠른 재구매 플로우 (Quick Re-order) *(신규)***:
   - 헤더 1-Click 재구매 버튼 ➔ MYPAGE (P-11) ➔ 지난 주문 옵션(겹수/자수) 그대로 불러오기 ➔ 원터치 결제
