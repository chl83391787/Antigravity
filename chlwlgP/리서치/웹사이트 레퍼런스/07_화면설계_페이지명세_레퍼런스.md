## 2. 핵심 화면 상세 인터랙션 명세 (기존 + 신규 확장)

### 2.1 P-01: 메인 화면 (HOME)
* **목적**: 맑고 고요한 첫인상 부여, 4차 정련 가치 전달 및 주요 서비스로의 신속한 라우팅
* **인터랙션 명세**:
  * 마우스 이동 시 배경 캔버스에서 잔잔한 3D 물결(Ripple) 반응 ([Izanami](https://izanami-official.com/) 벤치마크)
  * 첫 스크롤 다운 시 [Lenis](https://lenis.darkroom.engineering/) 스무스 스크롤로 자연스럽게 브랜드 스토리 섹션 전환

### 2.2 P-07: 상품 상세 화면 (Product Detail & Customizer)
* **목적**: 원단 텍스처 검증, 자수 커스텀 시각화, 단가 투명성 제공을 통한 결제 전환
* **인터랙션 명세**:
  * **좌측**: 이미지 마우스 호버 시 500% HD 돋보기 뷰어 활성화 ([Bottega](https://www.bottegaveneta.com/)), 세탁 전/후 1:1 수축 비교 슬라이더
  * **우측**: 실시간 Canvas 자수 입력창(문구, 3종 폰트, 5종 실 색상 선택 시 100ms 내 실물 합성) ([Nike By You](https://www.nike.com/nike-by-you))
  * **단가 계산기**: 낱장 vs 3장/5장 세트 선택 시 장당 절감 금액 및 최종 결제 금액 실시간 계산
  * **유효성 검사**: 자수 문구 15자 초과 입력 시 즉각적인 경고 텍스트 출력
  * **모바일 대응**: 화면 하단 고정 스티키 CTA 바 (장바구니 담기 / N Pay 1초 결제)
