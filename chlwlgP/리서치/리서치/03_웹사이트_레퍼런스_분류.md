# Flottelier Reference Classification

> 목적: 웹사이트 레퍼런스를 역할별로 빠르게 조회하기 위한 분류 문서.
> 이 문서는 '왜 좋은지'를 깊게 분석하지 않고, 어떤 요소를 참고할 사이트인지 구분하는 데 사용한다.

## 1. Color & Mood

### mira
- URL: https://mira-inc.jp/
- 분류: Color / Mood / Texture
- 참고 요소:
  - 부드럽고 맑은 색상
  - 저채도 컬러
  - 은은하게 번지는 색감
  - 공기감 있고 몽환적인 분위기
- 중요도: Core Reference

### JIII ATELIER
- URL: https://jiii-atelier.com/
- 분류: Color / Mood / Graphic Texture
- 참고 요소:
  - Pale tone
  - 저채도 파스텔
  - 흐릿하게 섞이는 색
  - 감성적이고 실험적인 비주얼
- 중요도: Core Reference

## 3. Interaction & Motion

### Izanami
- URL: https://izanami-official.com/
- 분류: Fluid Interaction / Cursor Interaction
- 참고 요소:
  - 마우스를 움직일 때 물처럼 반응하는 인터랙션
  - 유체적인 화면 반응
- 중요도: Core Interaction Reference

### NUSET
- URL: https://nuset.jp/
- 분류: Scroll Interaction / Fluid Transition
- 참고 요소:
  - 첫 화면에서 스크롤을 내릴 때 물처럼 움직이는 전환
  - 부드럽게 이어지는 화면 변화
- 중요도: Core Interaction Reference

### mud Inc.
- URL: https://mud.co.jp/
- 분류: Fluid Interaction
- 참고 요소:
  - 물처럼 움직이는 일부 인터랙션
- 제외 요소:
  - 전체 디자인
  - 색상
  - 기타 시각 요소
- 중요도: Partial Reference

## Rule

레퍼런스 사이트 전체를 그대로 모방하지 않는다.

각 사이트는 지정된 분류의 요소만 참고하며, 서로 다른 레퍼런스의 장점을 Flottelier 브랜드 전략에 맞게 조합한다.
