# 🎨 Flottelier (플로텔리에) 브랜드 로고 탐색 및 생성 가이드 (logo.md)

## 1. 기본 명령 및 트리거 규칙 (Trigger Rules)
* **명령어**: `레퍼런스 수집 시작해` 또는 `로고 실행해`
* **수집 동작**:
  - `C:\chlwlgP\로고\input\` 폴더 안의 이미지 파일(`로고 초안.png`, `영롱함.png`)을 참고한다.
  - `C:\chlwlgP\로고\로고레퍼런스\` 폴더 안에 있는 양식/이미지 스타일(유기적 아르누보 엠블럼, 흑백 플루이드 라인)처럼 핀터레스트에서 유사한 로고 이미지를 탐색한다.
  - 탐색/찾은 이미지는 캡쳐 후 `C:\chlwlgP\로고\output\` 폴더 안에 `.jpg` 파일(`younglong_reference_<순번>.jpg`)로 생성 및 저장한다.

## 2. 필수 프롬프트 및 파이프라인 5대 규칙 (Core Prompt Rules)

1. **flow 이미지 생성 기능 활용 프롬프트 작성**
   - 이미지 생성 도구(Flow)에서 정확하고 독창적인 2D 흑백 로고를 생성할 수 있는 최적의 파라미터 프롬프트를 작성한다.

2. **output레퍼런스를 분석하여 flow에 활용할 수 있는 프롬프트로 작성한다**
   - `output` 폴더에 수집 및 저장된 레퍼런스 이미지의 시각적 형태(네거티브 스페이스, 멜팅 획, 유기적 곡선 실루엣 등)를 정밀 분석하여 프롬프트에 반영한다.

3. **영문 프롬프트로 작성한다**
   - AI 이미지 생성 모델의 정밀성 및 품질 극대화를 위해 반드시 **100% 영문(English)**으로 작성한다.

4. **실행한 이미지는 "재실행"명령이 입력되기 전까지 다시 작성하지 않는다**
   - 한 번 프롬프트가 작성되어 `flow.md`에 기록된 이미지에 대해서는 사용자의 명시적인 **"재실행"** 또는 **"프롬프트 재작성"** 명령이 입력되기 전까지 기존 프롬프트를 변경하거나 재작성하지 않는다.

5. **작성한 프롬프트는 output폴더안에 flow.md파일에 파일 이름을 대제목으로 작성하고 아래쪽에 프롬프트를 작성한다**
   - 도출된 프롬프트는 `C:\chlwlgP\로고\output\flow.md` 파일에 기록한다.
   - 문서 상단에는 대상 레퍼런스 파일 이름(예: `# younglong_reference_1.jpg`)을 대제목으로 작성하고, 하단에 영문 프롬프트를 기술한다.
