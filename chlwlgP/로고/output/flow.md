# 🚫 로고 프롬프트 공통 금지 항목 (#금지항목)

> **[필수 네거티브 프롬프트 명세]**
> * ❌ **No Korean text / No Hangul characters**: 한국어 글씨체/한글 텍스트 일체 제외 (영문 `Flottelier` 또는 텍스트 없는 순수 심볼만 허용)
> * ❌ **No Color**: 컬러, 파스텔, 수채화, 그라데이션 완전 금지 (단색 순수 검정 `#000000`만 허용)
> * ❌ **No Mockup**: 명함, 간판, 종이 질감, 실물 목업 일체 금지
> * ❌ **No 3D / No Shadows**: 3D 입체, 엠보싱, 그림자(Drop Shadow) 일체 금지 (순수 2D 플랫 벡터만 허용)
> * ❌ **Non-white Background**: 순수 흰색 평면 배경 (`#FFFFFF`) 외 다른 배경색 일체 금지
